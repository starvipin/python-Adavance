03 · Function map

          
What does each function do?

        

        
n means the number of nodes currently in the list.

      


      

        

          01
          
Node(value)
Creates a new node with data=value and initially sets next=None.

          O(1)
        

        

          02
          
insertAtEnd(value)
Finds the final node and connects its next reference to the new node.

          O(n)
        

        

          03
          
insertAtBegin(value)
Connects the new node to the old head, then makes the new node the head.

          O(1)
        

        

          04
          
insertAtMiddle(value, x)
Finds the node containing x and inserts a new node immediately after it.

          O(n)
        

        

          05
          
deleteLinkList(value)
Redirects the previous node's next reference to the node after the target.

          O(n)
        

        

          06
          
printLinkedList()
Starts at head, follows each next reference, and prints every node's data.

          O(n)
        

      

    


    

      

        

          
04 · Why this version

          
Simple rules make the code easier to learn.

        

        
The visualizer and the code below now use the same safe version, so there is only one implementation to understand.

      


      

        

          One rule · Delete
          
One link update removes any non-head node

          
prev.next = current.next makes the previous node skip the target. It works for both middle and final nodes.

          
10204030

        

        

          Clear names
          
current is always the node being inspected

          
For searching and printing, the same pointer name moves one node at a time. prev simply stays one step behind during deletion.

          current = current.next
        

        

          Safety first
          
An empty list is handled before reading node data

          
The function checks whether current is None before using current.data or current.next.

          if current is None: return False
        

        

          Stop early
          
return ends the function when the job is done

          
Successful insertions and deletions return immediately. If a target is not found, the function reaches one clear return False.

          return True

class Node:
    def __init__(self, info, next=None):
        self.data = info
        self.next = next


class SinglyLinkedList:
    def __init__(self, head=None):
        self.head = head

    def insertAtEnd(self, value):
        temp = Node(value)

        if self.head is None:
            self.head = temp
            return

        current = self.head
        while current.next is not None:
            current = current.next
        current.next = temp

    def insertAtBegin(self, value):
        self.head = Node(value, self.head)

    def insertAtMiddle(self, value, x):
        current = self.head

        while current is not None:
            if current.data == x:
                current.next = Node(value, current.next)
                return True
            current = current.next

        return False

    def deleteLinkList(self, value):
        current = self.head

        if current is None:
            return False

        if current.data == value:
            self.head = current.next
            return True

        prev = current
        current = current.next

        while current is not None:
            if current.data == value:
                prev.next = current.next
                return True
            prev = current
            current = current.next

        return False

    def printLinkedList(self):
        current = self.head

        while current is not None:
            print(current.data, end=" ")
            current = current.next
        print()
